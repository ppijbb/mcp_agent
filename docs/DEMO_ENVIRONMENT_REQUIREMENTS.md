# Demo Environment Requirements

다음 Agent들은 실제 인프라, 하드웨어, 또는 클라우드 서비스가 필요합니다.
데모를 위해서는 별도의 시연 환경 구성이 필요합니다.

## 최소 구성 (로컬 개발 환경)

- Docker 또는 minikube
- 테스트용 계정 (GitHub, AWS/GCP/Azure 등)
- 로컬 개발 환경 구성

## 완전 구성

- 클라우드 계정
- Kubernetes 클러스터
- 모니터링 스택

## Agent별 요구사항

| Agent | 필요 구성 |
| --- | --- |
| Drone Scout Agent | 드론 하드웨어 또는 시뮬레이터 |
| AIOps Orchestrator Agent | 실제 서버/인프라, Kubernetes, 모니터링 시스템 |
| DevOps Assistant Agent | GitHub 계정, AWS/GCP/Azure, Kubernetes 클러스터 |
| AI Architect Agent | AI/ML 인프라, GPU 클러스터, 성능 벤치마크 환경 |
| Cybersecurity Agent | 보안 인프라, 방화벽, 보안 스캐닝 도구 |

## 참고

일부 Agent는 모의 데이터로 기능만 시연할 수 있습니다.
